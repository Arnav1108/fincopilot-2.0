# FinCopilot 2.0

FinCopilot is a financial research AI platform that enables investors, analysts, and finance professionals to interact with real-time and historical market data through a conversational interface. The platform combines a Next.js 14 frontend with Clerk authentication, a FastAPI backend powered by async PostgreSQL (with pgvector for semantic search), Celery-based background task processing, and OpenAI-driven language models — all orchestrated via Docker Compose — to deliver accurate, cited financial insights at conversational speed.
